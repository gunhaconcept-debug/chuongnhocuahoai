CHUỒNG NHỎ CỦA HOÀI - V4

QUAN TRỌNG
Bản V4 có Netlify Function để đọc tự động dữ liệu MonkeyD.
Để Function hoạt động đúng, hãy triển khai project qua Git (khuyên dùng GitHub)
hoặc Netlify CLI/API. Không dùng kiểu chỉ upload output tĩnh nếu muốn tự đọc MonkeyD.

SAU KHI DEPLOY ĐÚNG
- /api/monkeyd-meta sẽ hoạt động.
- Trang /admin.html: dán MonkeyD + YouTube/Audio + Shopee để tạo link.
- Link truyện tự đọc tên, ảnh, trạng thái, chương và thể loại từ MonkeyD.
- Truyện hiện tại có dữ liệu fallback sẵn để không hiện trang trống nếu API tạm lỗi.
